# Course release: machine-learning-foundations v18

A sanitized, portable copy of the **exact published v18** course for a fresh MongoDB. Generated by
`backend/scripts/exportCourseRelease.ts`; imported by `backend/scripts/importCourseRelease.ts`.

| File | MongoDB collection | Notes |
|---|---|---|
| `course.json` | `cmsCourses` | course pointer: published = `v18`, no draft pointer |
| `version.json` | `cmsCourseVersions` | the immutable published version (7 zones / 13 modules / 115 checkpoints) |
| `snapshot.json` | `curriculumSnapshots` | the structure learners are pinned to (marked active) |
| `packages/<packageId>@<rev>.json` | `cmsAnimationPackages` | the 115 frozen animation packages (HTML/CSS/JS, manifest, Package Trace) |
| `manifest.json` | — | format + schema version, expected counts, sha256 of every file above |

Files are canonical EJSON (ObjectIds, dates and numbers round-trip exactly) with sorted keys, so re-exporting the same
data gives identical files (only `manifest.exportedAt` changes). Every user reference was replaced by a placeholder id.

**Not included, by design:** users, refresh tokens, enrollments/progress/XP, notes, attempts, reward events, drafts.
Create learners by registering; create the first admin with `backend/scripts/promoteAdmin.ts`.

```bash
cd backend && export MONGO_URI=... MONGO_DB_NAME=<empty database>
npx tsx scripts/importCourseRelease.ts --in=../deployment/course-bootstrap --dry-run
npx tsx scripts/importCourseRelease.ts --in=../deployment/course-bootstrap
# prove a restore equals the source (two databases on one server):
npx tsx scripts/verifyCourseRelease.ts --course=machine-learning-foundations --version=v18 --source-db=<src> --target-db=<dst>
```

Regenerate after a new publish (explicit version required, empty output directory):
`npx tsx scripts/exportCourseRelease.ts --course=machine-learning-foundations --version=<vN> --out=../deployment/course-bootstrap`.
The importer verifies checksums, that every referenced package is present and frozen, counts, and a valid Package Trace
for each package; it reports `CREATE / REUSE / CONFLICT` per document and refuses to overwrite a different existing
document without `--force-overwrite` (take a backup first).
